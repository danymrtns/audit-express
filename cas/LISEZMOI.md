# Dossier des cas en cours

Déposez ici les documents à auditer (PDF, images, tableaux). La commande `/audit-cas` de Claude y écrit `cas-en-cours.json`, que la page charge avec l'adresse `http://localhost:4173/?cas=cas-en-cours`.

Tout ce dossier, sauf ce fichier, est ignoré par Git : les données d'un client ne sont jamais envoyées sur GitHub.
